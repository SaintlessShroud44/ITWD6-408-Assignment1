JSON Rules

Important rules that must be adhered to in order to create valid JSON data:

Rule 1: Data is stored using key/value pairs

JSON stores information using a key followed by its corresponding value.

Code example: { "fname": "Shawn" }

Rule 2: Keys use double quotation marks

JSON property names must be surrounded by double quotation marks.

Code example: { "lname": "Peipi" }

Rule 3: A colon separates the key and value

A colon is placed between a key and its value.

Code example: { "gender": "Male" }

Rule 4: Values are separated by commas

When an object contains several key/value pairs, commas separate them.

Code example: { "fname": "Shawn", "lname": "Peipi" }

Rule 5: Objects use curly brackets

JSON objects begin with { and end with }.

Code example: { "provider": "Spark" }

Rule 6: Arrays use square brackets

Arrays contain a list of values inside square brackets.

Code example: [ "Apple", "Android" ]
