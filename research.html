Copyright & Creative Commons

Copyright protects original works such as text, images, music, videos, artwork and computer programs.

  1. Copyright: Copyright protection generally applies automatically when an original work is created.
  2. Attribution (BY): A person using the work must give appropriate credit to the creator.
  3. ShareAlike (SA): Adapted material must be shared under the same licence.
  4. NonCommercial (NC): The material cannot be used primarily for commercial purposes.
  5. NoDerivatives (ND): The work may be copied and shared but modified versions cannot be distributed.
  6. Fair dealing in New Zealand: Copyright law allows certain limited uses of copyrighted material for purposes such as criticism, review, news reporting, research and private study.

Privacy & Privacy Policy

A privacy policy explains how a website collects, stores, uses and protects personal information.

New Zealand's 13 Privacy Principles:

  1. Purpose for collecting personal information.
  2. Source of personal information.
  3. Collection of information from the individual.
  4. Manner in which information is collected.
  5. Storage and security of personal information.
  6. Access to personal information.
  7. Correction of personal information.
  8. Checking accuracy before information is used.
  9. Personal information should not be kept longer than necessary.
  10. Limits on the use of personal information.
  11. Limits on disclosure of personal information.
  12. Disclosure of personal information outside New Zealand.
  13. Rules relating to unique identifiers.

Search Engine Optimisation

Search Engine Optimisation (SEO) helps search engines understand a website and can improve its visibility in search results.

  1. Use relevant keywords: Include words that users are likely to search for in titles, headings and content.
  2. Create quality content: Publish useful, original and relevant information.
  3. Use descriptive page titles: Give each page a meaningful <title>.
  4. Use headings correctly: Use headings such as <h1>, <h2> and <h3>.
  5. Add image alt text: Descriptive alternative text improves accessibility and helps explain images.
  6. Improve website speed: Faster loading improves the user's experience.
  7. Make the website responsive: The website should work correctly on desktops, tablets and phones.

Web Publishing & Hosting

Web hosting stores website files on a server so that the website can be accessed through the Internet.

  1. Reliability: Choose a provider that offers high uptime and dependable servers.
  2. Performance: Fast servers and suitable locations can improve loading times.
  3. Security: Look for HTTPS/SSL support, backups, malware protection and security tools.
  4. Technical support: Reliable customer support is important when technical problems occur.
  5. Price: Compare initial prices, renewal prices and included features.
  6. Storage and bandwidth: The hosting plan should provide enough resources for the website.
  7. Scalability: The hosting plan should be able to grow as traffic increases.

Web Performance & Maintenance

Ways to reduce page loading time:

  1. Compress and resize large images.
  2. Minify CSS and JavaScript files.
  3. Reduce unnecessary HTTP requests.
  4. Use browser caching.
  5. Use lazy loading for images and media.

Important website maintenance tasks:

  1. Regularly update website content.
  2. Check for and repair broken links.
  3. Keep website software and libraries updated.
  4. Create regular website backups.
  5. Monitor website performance, security and errors.

Common Web Security Threats

  1. Phishing: Fake emails or websites attempt to steal passwords or personal information.
    Prevention: Check links carefully and use multi-factor authentication.
  2. SQL Injection: Attackers enter malicious SQL commands into website inputs.
    Prevention: Use parameterised queries and validate user input.
  3. Cross-Site Scripting (XSS): Malicious JavaScript can be injected into web pages.
    Prevention: Validate and safely encode user-controlled information.
  4. Brute-force attacks: Attackers repeatedly try different passwords.
    Prevention: Use strong passwords, multi-factor authentication and login rate limits.
  5. Malware: Malicious software may damage website files or compromise web servers.
    Prevention: Keep software updated, monitor systems and create regular backups.
